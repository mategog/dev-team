Must fix · 1. A damaged save file loads as an empty shop

What this is
The store loads a saved JSON file and checks it for corruption.
Problem
A version 1 save file with orders: null passes the check and loads as a shop with no orders, instead of being rejected as corrupt.
Fix
Treat a missing or null orders list as a corrupt file and refuse to load it.
If we skip it
The orders are gone with no error, so nobody knows the file was damaged.
