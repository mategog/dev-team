# Examples

A fictional project ("Tally", a small habit-tracker web app) showing what dev-team writes into your repo. Nothing here is real data.

- `company/profile.md` — what `/dev-team:setup` produces.
- `company/briefs/streak-reminders.md` — a brief mid-build: status, next step, repo and baseline, approved scope (frozen) and owner checks.
- `company/briefs/streak-reminders/` — its plan and the log that lets a build resume.
- `company/decisions.md` — the decisions log.
